# شو أطبخ؟ 🍲

تطبيق ويب يقترح عليك وصفات حسب المكوّنات الموجودة في بيتك، ويعرض لك أين تشتري المكوّنات الناقصة من متاجر بلدك.

A web app that suggests recipes from the ingredients you already have, and links the missing ones to grocery stores in your country.

## الخطة

| المرحلة | المحتوى | الحالة |
|---|---|---|
| ١ — قاعدة الوصفات | وصفات حقيقية موثّقة بمصدرين على الأقل، بثلاث لغات (عربي/تركي/إنجليزي)، وقاموس مكوّنات موحّد بالمرادفات واللهجات | 🟡 جارٍ (7 مطابخ مكتملة، 253 وصفة) |
| ٢ — الواجهة ومحرك المطابقة | Next.js + Tailwind، تصميم للجوال أولاً، RTL، PWA، إكمال تلقائي بالمرادفات، مطابقة بالنِّسَب والبدائل، فلاتر، صفحة وصفة مع تعديل عدد الأشخاص | ⏳ |
| ٣ — ربط المتاجر حسب الدولة | `data/countries.json`، روابط بحث مباشرة داخل المتاجر، خرائط جوجل، قائمة تسوّق ومشاركة عبر واتساب | ⏳ |
| ٤ — (لاحقاً) | اقتراح وصفة بالذكاء الاصطناعي، إدخال بالصوت/الصورة، حسابات ومفضلة، توسيع القاعدة | ⏳ |

التقدّم التفصيلي وعدد الوصفات في [`PROGRESS.md`](PROGRESS.md).

## البنية

```
data/
  recipes/          دفعات الوصفات (٢٥ وصفة كحد أقصى لكل ملف)، مثل syrian-01.json
  ingredients.json  قاموس المكوّنات الموحّد (أسماء، مرادفات، فئة، بدائل، كلمات بحث المتاجر)
  cuisines.json     المطابخ والمناطق والأعلام والأهداف لكل مطبخ
  meta.json         تسميات الفئات والوحدات وأنواع الوجبات بثلاث لغات
  tags.json         الوسوم المسموحة
scripts/            سكربتات التحقق والإحصاء والتنسيق (Node.js بدون مكتبات)
docs/DATA_SCHEMA.md توصيف هيكل البيانات وقواعده
```

## الأوامر

يتطلب Node.js 20 أو أحدث، ولا يحتاج إلى `npm install` في هذه المرحلة.

```bash
npm run check                          # فحص التنسيق + التحقق من صحة كل البيانات
npm run stats                          # إحصائيات + ١٠ وصفات عشوائية للمراجعة
node scripts/stats.mjs --sample 5 --seed 42
npm run format                         # إعادة تنسيق ملفات JSON
```

## قواعد البيانات

- كل وصفة حقيقية ومعروفة، ومذكور لها مصدران على الأقل من موقعين مختلفين في حقل `sources`.
- خطوات التحضير مكتوبة بصياغتنا وليست منسوخة من المواقع.
- لا نستخدم صور المواقع؛ النسخة الأولى تعرض أيقونة لكل نوع طبق.
- كل وصفة عليها علامة `halal`، ويتحقق السكربت من اتساقها مع المكوّنات (وكذلك نباتي/نباتي صرف/خالٍ من الغلوتين).
